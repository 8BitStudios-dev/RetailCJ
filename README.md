# RetailCJ

PLGame — gioco di gestione retail.

## Avvio locale

Dalla cartella della repository:

```sh
python3 -m http.server 8000
```

Apri http://localhost:8000 nel browser.

## Test

Con Node.js installato:

```sh
node --test tests/specialist-mechanics.test.cjs
```
